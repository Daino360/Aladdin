# Aladdin
A repository to save all progress of my thesis based on the paper [Genie: Generative Interactive Environments](https://arxiv.org/abs/2402.15391)

## Envs
In this directory there are three files:
 - genienv.yml (it contains dependencies necessary for open-genie)
 - jafarenv.yml (it contains dependencies necessary for jafar)
 - procgen38.yml (it contains dependencies necessary to create both dataset) [Python 3.8]
